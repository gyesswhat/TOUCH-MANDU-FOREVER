# 만두

래브라도 강아지 "만두"의 사진을 문지르면 털이 손길을 따라 눕고, 꼬리를 흔들고, 입을 벌리는 단일 웹 페이지다. 빌드 과정 없이 `index.html` 하나가 WebGL2로 사진, 털, 배경을 모두 그린다. 배포 주소는 https://mandu.gyesswhat.dev/ 이다.

## 로컬 실행

```
python3 -m http.server
```

실행한 뒤 브라우저에서 `http://localhost:8000/`에 접속한다. 소리는 화면을 한 번 누른 뒤에 켜진다.

주소 끝에 `?map`을 추가하면 털 길이와 부위를 나타내는 부위 지도가 사진 위에 겹쳐 보인다.
